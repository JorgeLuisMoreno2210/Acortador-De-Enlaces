# Acortador de Enlaces en Java (URL Shortener)

Aplicación desarrollada en **Java** diseñada para transformar direcciones web (URL) extensas y complejas en enlaces cortos, limpios y fáciles de compartir. Implementa lógica orientada a objetos para generar identificadores únicos, validar entradas y gestionar la asociación directa con cada destino original.

## Características principales
* **Generación de enlaces cortos:** Conversión inmediata de URLs largas en códigos o rutas compactas mediante algoritmos de generación de claves únicas.
* **Validación y control de URLs:** Verificación del formato de las direcciones ingresadas para garantizar enlaces consistentes y evitar duplicados o errores.
* **Mapeo y resolución rápida:** Búsqueda eficiente entre el código corto y la dirección web original para una redirección o consulta ágil.
* **Arquitectura orientada a objetos:** Código modular, limpio y estructurado bajo los principios de programación en Java.

## Lenguajes y herramientas utilizadas
* **Lenguaje principal:** Java (JDK)
* **Paradigma:** Programación Orientada a Objetos (POO)
* **Control de versiones:** Git y GitHub Desktop
